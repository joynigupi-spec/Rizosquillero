# 🌺 Rizos Quilleros · Landing Page Oficial

> Peluquería especializada en cabello rizado, ondulado y afro en **Barranquilla, Colombia**. Fundada por Estefani con más de 6 años de experiencia celebrando cada textura con corte en seco, terapia de ozono y productos 100% limpios.

---

## 🚀 Tecnologías Utilizadas

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Empaquetador & Dev Server:** [Vite 8](https://vite.dev/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Despliegue Automático:** GitHub Actions + GitHub Pages

---

## 📦 Cómo Publicar este Proyecto en GitHub

Sigue estos sencillos pasos desde la terminal en la carpeta de este proyecto:

### 1. Inicializar el repositorio Git
```bash
git init
git add .
git commit -m "feat: landing page oficial Rizos Quilleros"
```

### 2. Conectar tu repositorio de GitHub
Crea un nuevo repositorio en [GitHub.com](https://github.com/new) (puede ser público o privado) y vincula el control remoto:

```bash
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
```

---

## 🌐 Cómo Activar GitHub Pages (En 2 Clics)

El proyecto ya incluye el flujo automatizado en `.github/workflows/deploy.yml` y la configuración `base: './'` en `vite.config.ts`. Para publicarlo gratis en internet:

1. Entra a tu repositorio en GitHub.
2. Ve a la pestaña **Settings** (Configuración) > sección **Pages** (menú izquierdo).
3. En **Build and deployment** > **Source**, selecciona **GitHub Actions**.
4. ¡Listo! En 1 minuto tu página estará activa en:  
   `https://TU-USUARIO.github.io/TU-REPOSITORIO/`

## 💻 Desarrollo Local

Para correr el proyecto en tu computadora:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build

# 4. Previsualizar la versión de producción
npm run preview
```

## ✨ Características Principales

- **Reserva Interactiva de WhatsApp:** Generador automático de mensaje personalizado con nombre, servicio, textura de rizo y jornada.
- **Catálogo de Servicios 2025 (COP):** Precios reales en pesos colombianos divididos por categorías y combos especiales.
- **Guía de Texturas (Tipo 2, 3, 4 y Transición):** Educación para clientas sobre su tipo de rizo y recomendaciones de cuidado.
- **Antes y Después:** Casos de transformación real en Barranquilla con comparador interactivo.
- **Responsive Total:** Diseño optimizado para celulares, tablets y computadores de escritorio.
